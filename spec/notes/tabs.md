# Tabs

ECMA-376 Part 1 §17.3.3.32 places a tab at the next custom stop beyond the preceding laid-out content, then at the next multiple of `defaultTabStop` when no later custom stop exists. Section §17.15.1.25 supplies a 720-twip interval when the document omits that setting.

Custom stops are additive across paragraph-property layers (§17.3.1.38). The display resolves them in the order [the formatting hierarchy](./formattingHierarchy.md) fixes: document defaults, the table style, numbering-level paragraph properties, the paragraph style, and direct paragraph properties. A `clear` entry removes a stop inherited at the same position. Each effective stop remembers the layer that laid it down, with the document defaults and a table style counted as the style layer, because removing an inherited stop means writing a `clear` over it while a direct one is deleted from the paragraph's own list. The display creates the implicit stop a hanging indent carries at the indent's position, unless the paragraph writes a stop of its own there or the document's `w:noTabHangInd` compatibility setting (Part 4 §14.8.3.31) switches the implicit stop off; a `clear` at that position does not remove it, since §17.3.1.38 has the hanging indent always create it. Table-style conditional paragraph properties remain in their source XML but are outside the current paragraph display model.

The character a `decimal` stop aligns on is chosen from the run's `w:lang` locale, falling back to the paragraph's and then the document's. §17.18.84 does not fix the character, and `w:decimalSymbol` (§17.15.1.23) is a field-calculation setting the display does not read, so the locale's decimal separator is this project's choice.

The display model normalizes the Transitional `left` and `right` values to the logical `start` and `end` values. A `bar` entry is a drawing instruction under §17.18.84 and is therefore excluded when choosing the next positioning stop. The legacy `num` value is retained in the model but positioned as `start`, matching its compatibility role between a list label and paragraph content. Leader values remain part of the effective stop, while the display deliberately does not synthesize leader glyphs or bar lines. None of these display decisions replaces the preserved paragraph-property XML used for export.

When a `center`, `end`, or `decimal` stop would require its following text to overlap content already laid out on the line, the display keeps the following text at the current position. The selected custom stop and its source XML remain unchanged.
