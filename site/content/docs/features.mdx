title: Features
description: What the editor edits, what it preserves untouched, and its current limitations.

`@portone/docx-editor` edits common DOCX body content while preserving document structures
outside its editing surface.

This page is the user-facing support summary. API details live in
[Custom controls](/docs/custom-controls) and [Core API](/docs/core).

## Supported features

| Area | What you can do |
| --- | --- |
| Text formatting | Edit bold, italic, strikethrough, underline, palette or custom HEX colors, highlight, fonts, and font size. Supported document defaults and paragraph or character styles are reflected in the text and formatting controls. |
| Paragraphs | Apply paragraph styles, alignment, indentation, line spacing, line breaks, and page breaks. A paragraph marked keep with next, by itself or by its style, is shown on the same page as the start of the block after it. |
| Tabs | Insert, paste, format, navigate, select, and align document tabs using the document's automatic interval and effective paragraph stops. |
| Lists | Create and edit common bullet and numbered lists, including nested levels. A list is drawn the way its own definition asks: the format its numbers are counted in, where its counting starts over, what stands between a number and the text, and the character formatting the level puts on the number itself. A list that takes its numbers from a numbering style is drawn like any other. |
| Tables | Insert and remove rows, columns, and tables; merge, split, resize columns and rows, format, vertically align, and pad cells. A table style is displayed, its header row, closing row, edge columns, corners, and banded rows included. Long tables continue at safe row boundaries, repeating leading `tblHeader` rows. |
| Images | Insert, paste, drop, select, and resize inline images. |
| Hyperlinks | Create, change, remove, and open external links. |
| Comments | View anchored threads; create, edit, reply to, resolve, reopen, and delete plain-text comments. Each comment records its author, so editing and deleting stay with them. |
| Footnotes and endnotes | View references and plain-text note bodies while editing surrounding text. A reference is preserved rather than edited: a selection running across one cannot be replaced, so typing or deleting over it leaves the text as it stands, and the picture, line break and page break controls are unavailable while it is held. |
| Headers and footers | Visually preview the first section's plain-text first, even, and default stories, including decimal `PAGE` and `NUMPAGES` fields. |
| Content controls | Edit or lock supported text and table-cell controls. |
| Clipboard | Paste supported character formatting, paragraphs, destination-matched heading styles, line breaks, links, and common lists. Unsupported web styling is reduced to readable text. |
| Editor | Use built-in controls, selectable document zoom, undo and redo, keyboard navigation, and IME composition, in a read-only, comment-only, or editing mode. |

## Keyboard shortcuts

`Mod` is Command on macOS and Control elsewhere.

| Keys | What happens |
| --- | --- |
| `Enter` | Splits the paragraph, and the new paragraph keeps the original's formatting, as Word does. In an empty list item it leaves the list instead. |
| `Shift+Enter` | Inserts a line break. |
| `Mod+Enter` | Inserts a page break. |
| `Mod+B`, `Mod+I`, `Mod+U` | Toggles bold, italic, and underline. |
| `Mod+Shift+X` | Toggles strikethrough. |
| `Mod+K` | Opens the link panel over the selection. With nothing to link it reports that it did nothing, so the browser keeps its own binding. |
| `Mod+Z` | Undo. |
| `Mod+Shift+Z`, `Mod+Y` | Redo. |
| `Tab` | Inside a table it moves to the next cell; in a list paragraph it increases the level; in an ordinary paragraph it inserts a document tab. |
| `Shift+Tab` | Moves to the previous cell, or decreases the list level. |
| `ArrowLeft`, `ArrowRight` | Moves the caret across a laid-out tab as one step. Holding `Shift` extends the selection instead. |
| `Escape` | Closes an open panel, menu, or link card and hands focus back to the paper. It also hides tooltips until the pointer or focus moves. |

Keys not listed here fall through to ProseMirror's base keymap, which covers ordinary caret
movement, selection, and deletion.
A keymap passed through the `plugins` prop sees events first, so an application can take over a
binding such as `Mod+K` without replacing the editor.

## Preserved content

| Content | Behavior |
| --- | --- |
| Additional Word character formatting and character styles | Existing formatting that the editor does not display or edit is preserved. |
| Bookmarks | Existing bookmark ranges are preserved at their document positions but are not displayed or editable. A selection running across one of the invisible markers cannot be replaced, so typing or deleting over it leaves the text as it stands, and the picture, line break and page break controls are unavailable while it is held. Move the selection clear of the marker to edit the text around it. |
| Document fields | Existing fields in the document body are preserved but not displayed or editable. |
| Section breaks | A paragraph carrying a section break keeps it. The paragraph cannot be joined away, since nothing puts a lost section back, and pressing Enter in it keeps the break on the last paragraph of the section instead of copying it onto both halves. |
| Tracked changes | Existing revision markup is preserved but not displayed or editable, a table's `w:tblGridChange` included. A rebuilt table is the exception in one place: the cells continuing a vertical merge are written from the cell that starts it, so properties of their own do not come along. |

## Current limitations

- A list counts in decimal numbers, decimal numbers with a leading zero, upper or lower letters, upper or lower Roman numerals, Ganada, Korean digits, or the Chinese counting system. A list counting in any other format is shown with decimal numbers, and a level numbered with a picture is shown with the character written beside it instead.
- ECMA-376 Strict packages are refused. A Transitional document must declare the WordprocessingML prefix `w` on its main part's root.
- Tab leader glyphs and bar lines remain preserved in OOXML but are not drawn.
- Visual page boundaries are approximate and may differ from Word or printed output. Keep lines together and widow control are preserved but not reflected in them.
- A selection running across the last paragraph of a section cannot be deleted, even when the section break is not what you meant to remove. Move the selection clear of that paragraph's boundary to edit the text around it.

## Preservation

Content outside the supported editing surface is not silently discarded. Untouched package parts
and document blocks are written back from their original XML, while placeholders retain structures
the editor cannot safely model.

What a given document kept this way is not a guess: `documentFidelity` lists it, and `importDocx`
returns the same list for a file opened outside the editor.

If a safe round trip cannot be guaranteed, import or export fails with a stable error code instead
of returning a damaged document. [Core API](/docs/core) documents the package limits and the
server parser requirements.
