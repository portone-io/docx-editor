## Editing tables

Insert and remove rows, columns, and tables.
Merge, split, and resize columns and rows, and format, vertically align, and pad cells.

A table inside a table cell is preserved rather than edited.

## Table styles

A table style is displayed, including its header row, closing row, edge columns, corners, and
banded rows.

## Long tables

A table that runs past the bottom of a page continues at a safe row boundary, and its header rows
repeat on each page it continues onto.

A new table is as wide as one line of body text on the paper of the section it goes into.

## Limitations

A table is fitted to the body width of its own section, and one wider than the sheet is drawn
shrunk to fit it while the saved file keeps the width the table was given.

A table is shown as a placeholder when its rows cannot be read, or when a bookmark or similar
marker sits right after a cell that only continues a vertical merge.
Other markers between rows or cells are kept and the table stays editable.

Deleting a row or column is unavailable when it would remove a marker carried between rows or
cells.

[Tables](/docs/editor-api/tables) in the Editor API lists the commands and queries behind these
controls.
