## Text formatting

Edit bold, italic, strikethrough, underline, palette or custom HEX colors, highlight, fonts, and
font size.
Document defaults and the paragraph or character styles the editor supports show up both in the
text and in the formatting controls.

## Paragraphs

Apply paragraph styles, alignment, indentation, line spacing, line breaks, and page breaks.
A paragraph marked keep with next, whether marked on its own or through its style, is shown on the
same page as the start of the block after it.

## Tabs

Insert, paste, format, navigate, select, and align document tabs.
Tabs land on the stops in effect for the paragraph, and on the document's automatic interval
where none apply.

## Lists

Create and edit bullet and numbered lists, including nested levels.
A list is drawn the way its own definition asks: the format its numbers are counted in, where the
counting starts over, what stands between a number and the text, and the character formatting the
level puts on the number itself.
A list that takes its numbers from a numbering style is drawn like any other.
Numbers can be counted in decimal, decimal with a leading zero, upper or lower letters, upper or
lower Roman numerals, Ganada, Korean digits, or the Chinese counting system.

## Limitations

A list counting in any other format is shown with decimal numbers, and a level numbered with a
picture is shown with the character written beside it instead.

Tab leaders and bar tabs are kept in the file but not drawn.

[Text and paragraphs](/docs/editor-api/text-and-paragraphs) in the Editor API lists the commands
and queries behind these controls.
