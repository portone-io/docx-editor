## Text formatting

Edit bold, italic, strikethrough, underline, palette or custom HEX colors, highlight, fonts, and
font size.
Document defaults and paragraph or character styles are reflected in the text and the controls.

A run that carries formatting but no text, such as a highlighted blank a form leaves to be filled
in, is drawn as a short box in its own highlight or shading.
Clicking the box and typing, composing, or pasting fills it: the text takes the blank's formatting,
whatever formatting pasted text carried, and the box goes.
A blank nobody filled goes back out in the file as it came.
A formatted run with no text and no highlight or shading of its own takes no room on the page.
[Content controls](/docs/features/preserved-content#content-controls) covers a blank inside a
control.

Typed text takes the formatting of the nearest text in its paragraph, before the caret or else
after it, passing over what is not drawn, such as a bookmark or a formatted run with no text.
In a paragraph with no text, it takes the formatting of such a run.

## Paragraphs

Apply paragraph styles, alignment, indentation, line spacing, line breaks, and page breaks.
A paragraph marked keep with next, directly or by its style, is kept with the block after it
where the [page layout allows it](/docs/features/pages-and-sections#page-boundaries).

## Tabs

Insert, paste, format, navigate, select, and align document tabs, on the paragraph's own stops or
the document's automatic interval.

## Lists

Create and edit bullet and numbered lists, including nested levels.
A list is drawn as its own definition asks for number format, restarts, the separator after the
number, and the formatting of the number itself, including a definition reached through a
numbering style.
A level's own indentation is not always followed; see the limitation below.
Numbers can be counted in decimal, decimal with a leading zero, upper or lower letters, upper or
lower Roman numerals, Ganada, Korean digits, or the Chinese counting system.

## Limitations

Paragraph-style indentation can make nested list levels line up at the same position.

Bold, italic, strikethrough, and small caps do not toggle off when two styles enable the same
property.

Text marked hidden is shown as ordinary text and is included when copied to another application.
All caps, double strikethrough, character spacing, and emphasis marks are preserved in the file
but not drawn.

A list counting in any other format is shown with decimal numbers, and a picture bullet as the
character written beside it.

Tab leaders and bar tabs are kept in the file but not drawn.

Word draws nothing for a highlighted run with no text, so the box shown for one does not appear
when the file is opened in Word.
A blank inside a hyperlink is not filled by typing; the text goes beside it.
Deleting everything typed into a blank does not bring the blank back.

[Text and paragraphs](/docs/editor-api/text-and-paragraphs) in the Editor API lists the commands
and queries behind these controls.
