## Images

Insert, paste, drop, select, and resize inline images.
An image is fitted to the width of the sheet, and a pasted image also to the height its section
leaves.

## Hyperlinks

Create, change, remove, and open external links.
A link made on text inside a content control is written inside that control.

[Images and links](/docs/editor-api/images-and-links) in the Editor API lists the commands and
queries behind these controls.
