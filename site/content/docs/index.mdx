---
title: Documentation
description: A DOCX editor for React that reads and writes OOXML directly.
---

`@portone/docx-editor` opens a Word document in the browser, lets a person edit it, and writes
the file back out as DOCX.
It edits OOXML in place rather than converting to HTML and back, so what it does not model is
written back unchanged, and a round trip it cannot make safely fails with a stable error code.
